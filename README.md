# 🎡 RANDISE — Интерактивная Рулетка Участников (Dark Violet Edition)

Красивый, современный веб-сайт с колесом фортуны в темно-пурпурном стиле, горизонтальной лентой рулетки, автоматическим пьедесталом лидеров (1-е, 2-е, 3-е места) и полноэкранным празднованием победы.

---

## 🚀 Как запустить

Сайт полностью автономен и работает без дополнительных серверов и библиотек.

### Способ 1:
Дважды кликните по файлу **`index.html`** в папке проекта — он сразу откроется в браузере.

### Способ 2 (через Python):
```bash
python -m http.server 8000
```
И откройте в браузере: `http://localhost:8000`

## 🎨 Новые и ключевые возможности

1. **Темно-фиолетовый / пурпурный дизайн**:
   - Глубокий затемненный фон с неоновыми аметистовыми и пурпурными градиентами (`#0a0312`).
   - Полупрозрачные стеклянные панели (Glassmorphism) с фиолетовым свечением.

2. **Полноэкранное объявление победителя (на весь экран)**:
   - При выпадении участника всё окно затемняется и на весь экран выводится крупная победная карточка:
     > **🎉 Айя выиграла 1 место!**
   - Выводится золотая корона, бейдж места (`🥇 1 МЕСТО`) и цветной аватар.
   - Победитель **автоматически исключается из списка участников** справа.
   - Автоматически запускается праздничный салют из конфетти 🎊.

3. **Последовательные призовые места (1-е ➔ 2-е ➔ 3-е место)**:
   - Первый прокрут рулетки разыгрывает **1-е место** (`🥇 1 место`).
   - Второй прокрут разыгрывает **2-е место** (`🥈 2 место`).
   - Третий прокрут разыгрывает **3-е место** (`🥉 3 место`).
   - На кнопке вращения и в окне победителя всегда видно, какое место сейчас на кону!

4. **Две главные кнопки управления списком**:
   - 🔄 **«Обновить все»**: кнопка сброса — возвращает всех выбывших участников обратно в прежний список, очищает пьедестал и сбрасывает раунды к 1-му месту.
   - 🗑️ **«Удалить все»**: полностью очищает список участников для быстрого ввода новых с нуля.

5. **Таблица и добавление участников**:
   - Ввод имени прямо в нижнюю строку таблицы или через верхнее поле ввода.
   - Добавление по нажатию клавиши **Enter**.
   - У каждого участника свой яркий, сочный индивидуальный цвет.
   - Имена на рулетке контрастно подсвечены и отлично читаются при быстром вращении.

6. **Два режима рулетки**:
   - 🎡 **Колесо Фортуны**: круговая рулетка с физикой замедления и звуковыми щелчками.
   - 🎰 **Лента Рулетки (CS:GO style)**: плавное горизонтальное перелистывание карточек.
   - Горячая клавиша: **Пробел** запускает рулетку или закрывает окно победы.
